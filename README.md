# Contactos IESS - .NET MAUI

Aplicación multiplataforma para registrar contactos y consultar sus datos junto con una estimación del aporte al IESS.

## Funciones

- CI de 10 dígitos, RUC de 13 dígitos o pasaporte.
- Validaciones de identificación, nombres, fecha, correo y salario.
- Resumen con salario, aporte personal IESS (9,45 %), salario neto y aporte patronal referencial (11,15 %).
- Exportación del resumen a `.txt` mediante las opciones de compartir del dispositivo.
- Estilos implícitos en el formulario, estilos explícitos en el resumen e ilustraciones SVG.

Las tasas corresponden al trabajador del sector privado bajo relación de dependencia según la información del IESS. El cálculo es informativo y no reemplaza una liquidación oficial.

## Ejecutar

Abre `mmaldonadoTS3.slnx` con Visual Studio que tenga instalada la carga de trabajo .NET MAUI.
